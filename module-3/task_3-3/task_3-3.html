1. What is the difference between invoking and creating a function?

    2. Creating a function means defining what the function does, while invoking a function means running the code inside the function.

  2. Explain the syntax regarding semicolons and code blocks.

    3. Semicolons marks the end of the statements, while code blocks are defined by curly braces.

  3. What happens when we try to store values from a function when it doesn't return any?

    4. If a function doesn't explicitly return a value, it implicitly returns `undefined`. Attempting to store this value in a variable will result in that variable holding the value `undefined`.

  4. How do we separate parameters from each other when creating a function?

    5. Parameters are separated by commas when creating a function.

  5. Explain how parameter names are related during the invocation and creation of a function.

    6. A parameter is a the name of a variable defined in the function. Invocation calls the values from the parameters.

  6. Explain why a parameter is undefined when a function call is missing a parameter.

    7. When a function call is missing a parameter, that parameter is not assigned a value, making it undefined.

  7. Explain what happens when we use recursive functions.

    8. A recursive function is a function that calls itself to solve a problem in smaller steps.
