1. Where should you use constants, and where should you use variables? Can they all be constants?

    2. Constants should be used for values that do not change throughout the program. Variables should be used for values that can change. That means they cannot all be constants.

  2. How do parentheses affect the arithmetic outcome of an expression?

    3. Parentheses control the order of which the operations are performed in an expression. So what's inside the parentheses goes first.

  3. How do we limit floating-point numbers to a given number of decimals?

    4. We can limit the decimals using toFixed(). If we write 13.91478.toFixed(2) it will round to 13.91.

  4. How can we compare two floating-point values to see if they are equal (is 12.199999 the same as 12.2)?

    5. We can use isEqual = Math.abs(a - b) < 0.000001 to check if they are equal. This has a check accuracy up to 6 decimals.

  5. What do comparison operators return, and how can we check if they are FALSE or TRUE?

    6. Comparison operators return a boolean value, true / false. We can check if they are true or false using an if statement or by printing in the console. x= 5, y= 3 if (x > y) {console.log(true)}. console.log(x > y) will return true.

  6. How does the Math.random() function work, and what can it be used for?

    7. Math.random() generates a random number between 0 and 1. But it does not include 1, only the numbers in between. If we write Math.random() * 10 it generates a random number between 0 and 10, Which can be really useful.

  7. What is modulus (%), and when do we need this operator in mathematical operations?

    8. The modulus (%) tells us how much remains after dividing a number. So 12 % 4 would return 0, because there is no remainder. While 10 % 3 would return 1, since 10 divided by 3 has 1 remaining.
